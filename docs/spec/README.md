# Source specifications

The single source of truth for Atlas, added to the repo so the implementation can be checked against it directly (§0).

- [`atlas-ai-prd-tdd.md`](atlas-ai-prd-tdd.md) — the PRD + TDD (Parts I–III, §1–§61).
- [`Design.pdf`](Design.pdf) — the PRD Validation & Implementation Blueprint. **§B1** is the development-phase table this project follows (Phase 0 → 6); the ADRs in `docs/adr/` trace each phase to it.

These are reference documents, not build inputs. To read the PDF body (image-based) use the Read tool with a page range, or `pdftotext -layout` (poppler) for the text headings.
